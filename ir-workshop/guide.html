Tool guide

A fast cheat sheet for the four platforms in every team instance. No login needed to read this — get your actual credentials from the unlock page.

port 9000Case & alert management

Your team's incident cockpit. Alerts land here, become cases, and get worked through tasks and observables. Two teammates have org-admin rights; two have read access.

  1. Open the TheHive link for your team and sign in with your responder email + password.
  2. Go to Cases → New Case (or import an Alert). Use a case template if one exists.
  3. Add Tasks for each work item and Observables (IPs, hashes, domains, URLs) under the Observables tab.
  4. Select an observable and “Run analyzers” to enrich it via Cortex; flag confirmed ones as IOC.
  5. Set TLP/PAP, tag with MITRE ATT&CK, then close the case with a resolution when done.
Good to know. Org admins manage users, case templates and the org. Read-access members can view and comment but not change case structure. Export confirmed IOCs to MISP from an observable’s menu.
port 8080Threat-intelligence sharing

Where indicators live and correlate. Build Events full of Attributes (IOCs), tag and publish them, and pull in feeds. All four teammates are org admins.

  1. Open the MISP link and sign in (default admin is admin@admin.test until the super admin rotates it).
  2. Create an Event, set distribution + threat level, then add Attributes for each indicator.
  3. Tag with TLP and Galaxy/ATT&CK clusters; MISP auto-correlates matching attributes across events.
  4. Publish the event to make it available; use Feeds to ingest external intel.
  5. Grab your API key under My Profile → Auth keys to connect MISP with TheHive/Cortex.
Good to know. Keep distribution tight in the lab (your organisation only). STIX/CSV export lives under an event’s download menu.
port 9001Observable analysis & response

The enrichment engine behind TheHive. It runs analyzers against observables and responders to take action. All four teammates are org admins here.

  1. Open the Cortex link and log in with your responder login.
  2. Under Organization, review enabled Analyzers and add API keys for any that need them (VirusTotal, AbuseIPDB, …).
  3. Use Analyze to run an analyzer on a single observable, or trigger analyzers from inside TheHive.
  4. Check the Jobs view for reports; a failed job usually means a missing API key or a rate limit.
  5. Create an API key (Organization → Users) and paste it into TheHive so the two integrate.
Good to know. Cortex and TheHive talk over API keys — if analyzers don’t appear in TheHive, re-check the Cortex URL and key in TheHive’s config.
port 8065Team chat & coordination

Your team’s comms during an incident — channels, threads, file sharing. Everyone joins as a normal team member.

  1. Open the Mattermost link and log in with your responder email (username is responder<NN>) + password.
  2. Join your team and its channels; spin up a channel per incident if you like.
  3. Use threads and @mentions to keep investigation chatter organised.
  4. Drag in screenshots and files; use /commands for quick actions.
  5. Keep decisions and timelines here so the whole team stays in sync.
Good to know. Your login is your email, but your displayed username is responder<NN> (no @) — both appear on your unlock page.
The four tools integrate: Cortex enriches observables for TheHive, and MISP exchanges IOCs with both over API keys. Set those keys up early and the workflow clicks together.
